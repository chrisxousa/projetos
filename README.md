# Projetos · Christian Roberto

## [Rota PL-300](./rota-pl300)

Aplicação em português para acompanhar preparação, exercícios e revisões para a certificação Microsoft PL-300.

- Calendário e plano de estudos até a prova.
- Progresso por domínio e registros de prática, simulados, erros e dúvidas.
- Salvamento online, sincronização por conta e tratamento de alterações concorrentes.
- Importação dos registros da primeira versão e backup opcional.

[Acessar o site](https://christian-pl300-janeiro-2027.majorbatch4.chatgpt.site) · acesso privado à conta proprietária.

O código está público para estudo e portfólio; os registros pessoais não fazem parte deste repositório. Desenvolvido com auxílio de IA, a partir dos requisitos e objetivos de estudo de Christian.

**Estado atual:** autenticação pelo ChatGPT na hospedagem Sites. Login direto pelo Google ainda não implementado. Este repositório guarda o código; alterações aqui não são publicadas automaticamente no site.
